# 2026 이동수업 위치 확인 프로그램

학번(또는 학번 일부) / 이름 일부를 입력하면, 그 학생이 **지금 이 시각에 어디서 무엇을
하고 있는지**와 **일주일 전체 이동시간표**를 보여주는 구글 앱스스크립트 웹앱입니다.

## 데이터 출처

- 원본 파일: `2026 이동수업 위치 확인 프로그램.xlsx`
- **"시간표" 시트(학년/반별 요일·교시 전체 시간표)는 컴시간 알리미에서 내려받은
  데이터를 정리한 것**입니다. 학기 중 시간표가 변경되면 컴시간 알리미에서 다시
  받아 "시간표" 시트를 교체해주면 됩니다(시트 이름과 열 구성만 유지하면 코드
  수정 없이 그대로 반영됩니다).
- "N-M" 시트들(예: `2-1`, `3-12`)은 학교 자체 이동수업(선택과목) 편성 명단입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 데이터 파싱, 위치 계산 로직, 웹앱 서버 함수 |
| `Index.html` | 검색 UI, 결과(현재 위치 + 주간 시간표) 렌더링 |
| `2026 이동수업 위치 확인 프로그램.xlsx` | 원본 데이터 (Google Sheets로 변환해서 사용) |

## 배포 방법 (요약)

1. `2026 이동수업 위치 확인 프로그램.xlsx` 를 Google Drive에 업로드 후
   "Google Sheets로 열기"(또는 파일 > 다른 이름으로 저장 > Google Sheets)로 변환.
2. 변환된 시트에서 확장 프로그램 > Apps Script 열기.
3. 기본 `Code.gs`와 `Index.html`(신규 HTML 파일 생성) 내용을 이 저장소의
   `Code.gs`, `Index.html`로 교체.
4. 배포 > 새 배포 > 웹앱으로 배포 (실행 계정: 나, 액세스 권한: 학교 조직 내
   등 필요에 맞게 설정).
5. 문제가 있으면 Apps Script 편집기에서 `debugTimetableParse()` 함수를 직접
   실행해 로그(보기 > 로그)로 파싱 결과(교시 수, 시간 범위 등)를 확인.

## 핵심 로직 요약

- 신학번 5자리 = 학년(1) + 반(2, zero-pad) + 번호(2, zero-pad)
- 매 요일/교시마다 **학생 본인 원래 반의 "시간표" 칸 하나만** 보고 판단한다.
  - 칸에 `A_`, `B_` 같은 대문자 슬롯 문자가 붙어 있으면 → 이동수업 시간 →
    학생 명단 시트의 이동반 표(타임형A~F, 3학년은 추가로 공학군/미감비군)에서
    본인 슬롯을 찾아 실제 위치(이동반 번호 = 교실)를 알려준다.
  - 문자가 없으면 → 원래 반의 고정 수업 시간 → "시간표" 그 칸 내용
    (1번째 줄 = 과목명, 2번째 줄 = 교사명)을 그대로 사용해 자기 반 교실에서
    수업 중임을 알려준다(자율/창체/하교 포함). **이동수업이든 아니든 모든
    교시를 빠짐없이 채운다.**
- 3학년의 "공학/인공/일/중", "미감비/음감비"처럼 슬롯 문자가 헤더에 없는
  고정 선택군은, 시간표에서 발견됐지만 아직 학생 명단 컬럼과 연결되지 않은
  "남는 문자"(보통 G, H)를 헤더 텍스트를 `/`로 쪼갠 키워드와 실제 과목
  텍스트를 대조해 자동으로 매칭한다. 과목/학기가 바뀌어도 헤더 표기 규칙만
  유지되면 코드 수정이 필요 없다.
- 1학년은 개인별 이동수업 명단이 없으므로, 학번 패턴(`1`+반 2자리+번호
  2자리)만으로 "시간표" 시트의 해당 학급 행을 참조하는 가상 학생 정보를
  만들어 안내한다.

## 개발일지

### v1.0.0 (2026-08-29) — 최초 작성
- 요청: 학번/이름 일부로 검색해 현재 위치를 보여주는 웹앱.
- xlsx를 직접 열어 구조 분석: "시간표" 시트(학년/반별 요일·교시 표, 이동수업
  칸은 `A_과목명\n교사명` 형식) + "N-M" 학생 명단 시트(신학번/이름 + 타임형별
  과목/이동반 쌍).
- 이동수업 슬롯 문자(A, B, C...)를 하드코딩하지 않고 "시간표" 시트에서
  동적으로 추출하도록 설계(학기마다 데이터가 바뀌어도 코드 수정 불필요).
- 3학년의 "공학/인공/일/중", "미감비/음감비" 같이 문자 표기가 없는 고정
  선택군은 헤더 키워드 자동 매칭으로 연결.
- Code.gs / Index.html 작성, git 저장소 초기화 후 커밋.

### v1.1.0 (2026-08-29) — 1학년 지원 + 주간 시간표
- 요청: "1학년(학번 `1`로 시작)은 개인 명단이 없으니 시간표만 보고 안내해달라",
  "오늘 시간표 대신 지금 위치 + 일주일 전체 이동시간표를 교시x요일 그리드
  형태로 보여달라."
- `findGrade1Virtual_` 추가: 학번 패턴만으로 1학년 가상 학생 객체를 만들어
  "시간표" 시트 기준으로 안내.
- "오늘 시간표" 목록 방식을 폐기하고, 교시(행) × 요일(열) 그리드로 전체 주간
  이동시간표를 렌더링하도록 변경. 오늘 열/현재 교시 칸을 강조 표시.
- `formatOwnLocation_` 신설: 원래 반에 있을 때는 "(이동반 N)" 문구를 붙이지
  않도록 이동수업 위치 표기와 분리.

### v1.2.0 (2026-08-29) — 이동수업 판단 로직 단순화
- 요청: "고정 시간표도 전부 표시해야 한다. 이동수업일 때만 이동반 표를
  참고하고, 아닐 때는 전체 시간표에 나온 과목 이름을 참고해서 위치를
  적어라. (표에서 위 줄은 과목명, 아래 두 글자는 교사명)"
- 기존에는 "이 요일/교시에 그 학년 전체에서 어떤 슬롯 문자가 쓰였는가"를
  전체 반을 훑어 판단했는데(3학년 G/H처럼 소수 반만 호스트하는 슬롯 대응
  목적), 이 때문에 다른 반의 이동수업 시간대가 잘못 끼어들 여지가 있었다.
- **학생 본인 반의 그 칸 하나만 보고 판단**하도록 단순화. 문자가 없으면
  무조건 시간표 그 칸(과목명/교사명)을 그대로 사용 — 고정 시간표가 항상
  빠짐없이 채워지도록 수정.

### v1.3.0 (2026-08-29) — "방과 후" 오표시 버그 수정
- 증상: 테스트 시각을 14:00(5교시 시간대)로 넣었는데 "방과 후"로 표시됨.
  결과에 "일주일 이동시간표" 섹션 자체가 통째로 빠져 있었던 것이 결정적 단서.
- 원인: "시간범위 행"과 "교시번호 행"의 위치를 헤더 행 기준 고정 오프셋
  (+1줄, +2줄)으로 가정했는데, 실제 구글시트 구조에서 오프셋이 맞지 않아
  `periodTimes`(교시별 시간 정보)가 통째로 비었다. 교시 정보가 하나도 없으면
  무조건 "방과 후"로 처리되게 되어 있어, 08:40~16:30 사이 어떤 시각을
  넣어도 전부 "방과 후"로만 나왔다.
- 수정:
  - 고정 오프셋 대신, 헤더 아래 여러 줄을 훑어 **셀 내용 패턴**(교시 번호처럼
    보이는 셀 개수, "HH:MM~HH:MM"처럼 보이는 셀 개수)을 점수화해서 시간범위
    행/교시번호 행을 직접 탐색하도록 변경 — 표 구조가 한두 줄 밀려도 안전.
  - 시간 구분자 인식 강화: `~` 외에 `〜 ～ - – —` 도 허용.
  - 날짜/시각 계산 방식을 `Utilities.formatDate(tz, 'u')` 방식에서 UTC+9
    고정 오프셋 직접 계산으로 교체 — 스크립트 프로젝트의 타임존 설정과
    무관하게 항상 정확하도록 함.
  - 진단용 `debugTimetableParse()` 함수 추가(Apps Script 편집기에서 직접
    실행하면 로그로 파싱 결과 확인 가능).
- 검증: xlsx 원본 데이터를 Node.js로 직접 로드해 새 파싱 로직을 실행 —
  7개 교시 모두 정상 인식, 14:00 → 정확히 5교시(13:40~14:30)로 판별됨을 확인.

## 알려진 한계 / 유의사항

- 3학년 "공학군/미감비군" 시간대 자동 매칭은 정적 분석 기반 추론이므로
  실제 데이터로 꼭 검증할 것. 결과 화면에 "고정 선택시간 참고정보"로 항상
  별도 노출해서 자동판별이 어긋나도 교사가 눈으로 확인할 수 있게 해둠.
- 이동반 값이 텍스트(예: "교과교실2(3층)")인 경우 해당 반의 시간표 행이
  없어 담당교사 정보는 표시되지 않는다(위치명만 표시).
- "시간표" 시트는 컴시간 알리미 데이터를 옮긴 것이므로, 학기 중 시간표가
  바뀌면 컴시간 알리미에서 다시 받아 이 시트를 교체해야 한다.
