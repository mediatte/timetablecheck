# 이동수업 위치 확인 프로그램

학번(또는 학번 일부) / 이름 일부를 입력하면, 그 학생이 **지금 이 시각에 어디서
무엇을 하고 있는지**와 **일주일 전체 이동시간표**를 보여주는 구글 앱스스크립트
웹앱입니다.

고교학점제 등으로 학생마다 이동수업(선택과목) 시간표가 제각각일 때, "이 학생
지금 어디 있어요?"에 바로 답하기 위한 도구입니다.

## 주요 기능

- 학번 전체/일부, 이름 일부로 학생 검색 (동명이인 등 다중 검색 결과 지원)
- 현재 시각 기준 실시간 위치·과목·담당교사 표시
- 월~금 전체 이동시간표를 교시 x 요일 그리드로 표시 (오늘/현재 교시 강조)
- 1학년처럼 개인별 이동수업 명단이 없는 학년도 학급 시간표 기준으로 안내
- 특정 시각을 지정해 미리 확인해보는 테스트 모드

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 데이터 파싱, 위치 계산 로직, 웹앱 서버 함수 |
| `Index.html` | 검색 UI, 결과(현재 위치 + 주간 시간표) 렌더링 |
| `template.xlsx` | 개인정보·학교 식별 정보를 모두 제거한 샘플 데이터 |
| `CHANGELOG.md` | 버전별 변경 이력 |

> ⚠️ **`template.xlsx`는 샘플입니다.** 원본에서 교사명(`교사01`..), 학생
> 이름(`학생01`..), 과목명(`과목01`..)을 모두 코드로 치환하고, "고운누리실"
> 같은 학교 식별 정보도 일반화(`다목적실`)해서 만들었습니다. 학번·요일·교시·
> 이동반 번호 같은 **구조**는 프로그램 동작 확인을 위해 그대로 유지했습니다.
> 실제로 쓰려면 같은 구조로 학교의 실제 데이터를 채운 시트로 교체하면 됩니다.

## 데이터 구조

- **"시간표" 시트**: 학년/반(=이동반 번호)별 요일·교시 표.
  - 이동수업 칸: `A_과목명\n교사명` (맨 앞 대문자_ 는 슬롯 문자)
  - 고정 수업 칸: `과목명\n교사명`, 또는 `자율`/`창체`/`하교`
  - **컴시간 알리미에서 내려받은 데이터를 정리한 것**입니다. 학기 중 시간표가
    바뀌면 컴시간 알리미에서 다시 받아 이 시트만 교체하면 됩니다(시트 이름과
    열 구성만 유지하면 코드 수정 없이 그대로 반영됩니다).
- **"N-M" 시트들** (예: `2-1`, `3-12`): 학교 자체 이동수업(선택과목) 편성
  명단. 순번/신학번/이름 + (과목, 이동반) 쌍 컬럼들로 구성.
  - 신학번 5자리 = 학년(1) + 반(2, zero-pad) + 번호(2, zero-pad)
  - 2학년: 타임형A~E(5개). 3학년: 고정 선택군 2개(공학군/미감비군류) +
    타임형A~F(6개)

## 동작 원리 (요약)

매 요일/교시마다 **학생 본인 원래 반의 "시간표" 칸 하나만** 보고 판단합니다.

- 칸에 `A_`, `B_` 같은 대문자 슬롯 문자가 붙어 있으면 → 이동수업 시간 →
  학생 명단 시트의 이동반 표에서 본인 슬롯을 찾아 실제 위치(이동반 번호 =
  교실)를 알려줍니다.
- 문자가 없으면 → 원래 반의 고정 수업 시간 → "시간표" 그 칸 내용을 그대로
  사용해 자기 반 교실에서 수업 중임을 알려줍니다(자율/창체/하교 포함).
  **이동수업이든 아니든 모든 교시를 빠짐없이 채웁니다.**
- 3학년처럼 슬롯 문자가 헤더에 없는 고정 선택군(예: "공학/인공/일/중")은,
  시간표에서 발견됐지만 아직 학생 명단 컬럼과 연결되지 않은 "남는 문자"를
  헤더 텍스트 키워드와 실제 과목 텍스트를 대조해 자동으로 매칭합니다. 과목이
  바뀌어도 헤더 표기 규칙만 유지되면 코드 수정이 필요 없습니다.
- 1학년은 개인별 이동수업 명단이 없으므로, 학번 패턴만으로 "시간표" 시트의
  해당 학급 행을 참조하는 가상 학생 정보를 만들어 안내합니다.

## 배포 방법

1. 학교의 실제 데이터로 채운 xlsx(또는 `template.xlsx`)를 Google Drive에
   업로드 후 "Google Sheets로 열기"(또는 파일 > 다른 이름으로 저장 > Google
   Sheets)로 변환합니다.
2. 변환된 시트에서 확장 프로그램 > Apps Script를 엽니다.
3. 기본 `Code.gs`와 신규 HTML 파일(`Index`)의 내용을 이 저장소의 `Code.gs`,
   `Index.html`로 교체합니다.
4. 배포 > 새 배포 > 웹앱으로 배포합니다(실행 계정/액세스 권한은 필요에 맞게
   설정).
5. 문제가 있으면 Apps Script 편집기에서 `debugTimetableParse()` 함수를
   직접 실행해 로그(보기 > 로그)로 파싱 결과(교시 수, 시간 범위 등)를
   확인합니다.

## 알려진 한계 / 유의사항

- 3학년 "공학군/미감비군" 같은 고정 선택군의 시간대 자동 매칭은 정적 분석
  기반 추론입니다. 실제 데이터로 꼭 검증하세요. 결과 화면에는 "고정
  선택시간 참고정보"로 항상 별도 노출되므로, 자동판별이 어긋나도 눈으로
  확인할 수 있습니다.
- 이동반 값이 텍스트(예: "교과교실2(3층)")인 경우 해당 반의 시간표 행이
  없어 담당교사 정보는 표시되지 않습니다(위치명만 표시).
- "시간표" 시트는 컴시간 알리미 데이터를 옮긴 것이므로, 학기 중 시간표가
  바뀌면 컴시간 알리미에서 다시 받아 이 시트를 교체해야 합니다.
